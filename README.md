# Comparative Analysis of Machine Learning Models on Structured Data

This project performs a comparative analysis of two classical machine learning
classification algorithms on structured data using the Iris dataset.

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Dataset
- Iris dataset from scikit-learn

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix

## Results
Both models achieved high accuracy on the Iris dataset due to its well-separated
classes. Logistic Regression provides stable and interpretable results, while KNN
captures local neighborhood patterns.

## Tools & Technologies
- Python
- scikit-learn
- NumPy
- Matplotlib
- Seaborn
